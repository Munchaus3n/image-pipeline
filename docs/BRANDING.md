# Branding

## App Name

Cutout Studio

The repository may continue to use `image-pipeline` for internal paths and tooling until branch and packaging cleanup are complete.

## Logo Direction

The logo should be simple, readable, and useful at app-icon sizes.

Direction:

- Rounded square icon
- Cutout or mask shape
- Transparent checkerboard corner
- Simple edge or spark mark
- Clear silhouette at small sizes

Required sizes:

- 16x16
- 32x32
- 256x256
